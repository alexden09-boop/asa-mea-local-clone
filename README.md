# Локальная копия ASA

Это автономная рабочая копия публичной части [asa-mea.com](https://asa-mea.com/), снятая 17 августа 2026 года. Она не загружает production JavaScript, не обращается к API во время работы и не отправляет введённые в формы данные.

Публичная версия после публикации: [alexden09-boop.github.io/asa-mea-local-clone](https://alexden09-boop.github.io/asa-mea-local-clone/).

## Запуск

Самый простой вариант в PowerShell:

```powershell
.\start-local.ps1
```

После запуска откройте `http://127.0.0.1:4173/`. Окно PowerShell нужно оставить открытым; остановка сервера — `Ctrl+C`.

Либо запустите сервер вручную:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

## Что уже перенесено

- адаптивная главная страница со слайдером, всеми секциями и footer;
- мобильное меню и desktop dropdown академий;
- Football, Padel, Tennis и Fitness;
- Trial Enroll для Football, Padel и Tennis, а также отдельный Fitness Trainer route;
- Reservation и Private Training;
- Shop, Products, Our Team и Contact Us;
- локальные состояния Product Detail, Order Details и QR sections;
- Sign In, Sign Up и Forgot Password;
- Checkout и Notifications в их пустых публичных состояниях;
- полный локальный снимок публичных данных, стран, пакетов, товаров, команды и контактов в `data.js`;
- оригинальные локальные шрифты и изображения без сетевых runtime-зависимостей.

Навигация использует hash-маршруты (`#/academy/6` и т. п.), поэтому backend для разработки дизайна не нужен.

## Структура

- `index.html` — безопасная HTML-оболочка и CSP;
- `styles.css` — вся визуальная система и responsive-режимы;
- `app.js` — локальный роутер, шаблоны страниц и интерактивность;
- `data.js` — зафиксированный снимок публичного API;
- `assets/images` и `assets/fonts` — локальные runtime-ассеты;
- `.clone-ui/source` — доказательная база: DOM, контент, формы, API, скриншоты и production-ассеты только для сверки;
- `.clone-ui/plan` — токены, карта секций, ассеты и отчёты сравнения.

На финальном прогоне проверены 23 публичных hash-маршрута. Локальные контрольные изображения с префиксом `clone-` сохранены рядом с соответствующими исходными кадрами в `.clone-ui/source/.captures`.

## Осознанные ограничения

На исходном сайте в момент снятия копии не загружались некоторые gallery-, fitness-, shop-, product- и team-изображения. В копии эти состояния представлены серыми карточками с красно-чёрным индикатором, чтобы не придумывать несуществующий контент. Авторизация, покупка, OTP и отправка форм визуально воспроизведены, но отключены: локальная версия предназначена для безопасной работы над дизайном и анимацией.
